## [2.38.0] - 2026-11-07

> 区块层对齐逆向源码：**色块来自区块填充，不是陆地纹理**。

### Changed

- **区块样式三件改回逆向源值**（`decoded.js@131642` / 分析文档 §3.7）：
  填充不透明度 `REGION_FILL_ALPHA` 0.10 → **0.30**、边界线宽 `REGION_BORDER_PX`
  1.2 → **3 px**、边界色 `REGION_BORDER_COLOR` `#27352e` → **`#73562d`**、
  `REGION_BORDER_ALPHA` 0.32 → **1**。2.27.0 把 alpha 压到 0.10 是"在错误的维度上
  补偿"——参考实现的 alpha 比我们**更高**却不显色，靠的是"只有一级、≤20 块"；
  压 alpha 会把边界一起压淡，症状正是"读不出分块、陆地一片单一"。线宽与填充是**一对**
  参数：只抬 alpha 不抬线宽，面有层次而线仍是发丝，分块反而比改前更糊。
- **静态层次表抬平**：`REGION_LEVEL_FILL_SCALE` `[1, .75, .58, .45]` →
  `[1, .92, .86, .80]`。旧表是 2.36.0 在"LOD 还没接到区块容器上、四级同亮"时的补偿，
  郡级填充只剩 0.10 × 0.45 = 0.045；LOD 接管"压数量"之后，静态表只该保留"密度差"
  这一份，再往下压就是重复 2.27.0 那条错的补偿路。
- **取色随 alpha 重算**：兄弟色相跨度 `REGION_WOBBLE.hueSpread` 3° → **8°**、
  生成器饱和 0.10~0.16 → **0.13~0.21**。人眼看到的色差 ≈ 色相差 × 填充 alpha：
  改前 3° × 0.10 ≈ 0.3 个色阶，兄弟块**根本分不出来**（"单一"的另一半成因）；
  现在约 8 倍感知差。仍不回到 15°——那会跨过同族界线，"一块被分成几份"读成
  "不相干的几块"。手画取色（`manualRegionColor`）的偏移量跟着 `hueSpread` 走，
  自动从 ±6° 变成 ±16°，无需单独改。

### 未改动（避免误判为遗漏）

- **陆地纹理层不动**：逆向源码里陆地层就是"同一张可平铺地表纹理 + 40px 内羽化"
  （2.28.0 `P2-1` 已对齐），色块不在这。本批刻意**不**在陆地层再叠一套程序色块——
  两套带色相的系统叠加只会让观感更脏。要调陆地材质仍走 `coastBake.ts`。
- 选中高亮三笔（`R-REG-05` 回归基线）、区块几何/贴岸/掩膜/共享边去重（2.37.0）、
  `levelAlphas` 的四层共用（区块/折线/素材/地名同呼吸）均逐参数不变。

### 验测

- `regions.test.ts` 新增「区块样式与密度」4 条：① 三件 = 源值 + 线面浓度比 10:3；
  ② 任意缩放下**至多一级**权重 > 0.5（两级同时 > 0.5 需 `t₁ - t₂ > 1`，`t ∈ [0,1]`
  数学上不可能）；③ 全图视角（fit 0.62~0.80）主导层级 = 洲、**12 块 ≤ 20**（参考的
  `countries` 上限）且主导权重 > 0.85；④ 0.30 填充下同级区块合成色两两平均差
  ≥ 8/255（alpha 退回 0.10 时该值只剩 3.6 → 这条是回退探针）。
- `regionEdit.test.ts` 的 `manualRegionColor` 用例阈值改为跟着 `hueSpread` 计算，
  不再写死角度（写死会让"放宽色相跨度"变成假红）。
- `tsc --noEmit -p tsconfig.app.json` 零错误；`src/windows/MapWindow` 全量
  **45 文件 / 759 用例全绿**；改动的 5 个文件 `eslint` 零告警。

### 已知未对齐（单列待办）

- `LOD_BLOCK_PX = 360` ⇒ 自然缩放下同屏 ≈ `4 × 视口面积 / 360²` ≈ 30 块（**与层级无关**）。
  国家一级（48 块）在"视口仍覆盖大半张图"的缩放下同屏可到 ~40 块，超过参考的 20。
  要压到 ≤20 需把 `LOD_BLOCK_PX` 提到 ≈500，但那会**同时改掉素材与地名的层级节奏**
  —— 属跨元素改动，留待单独拍板（见 `docs/review/map-vs-reference-render-analysis.md` §9 `ALGN-2`）。
- **旧图提示**：区块颜色是存进文档的（`MapRegion.color`），旧存档的色相跨度仍是 3°。
  想拿到新取色需对旧图执行一次「重新生成分区」；不重生成时 α / 线宽 / 边界色 /
  层次表这四项是渲染期常量，旧图立即生效。
