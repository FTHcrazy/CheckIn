# Changelog · 2.39.x

## [2.39.0] - 2026-11-07

> 区块层第二轮：**相邻国家要读得出不同、国名要上图上岸**。

### Changed

- **区块配色改成"固定色板 + 邻接校正"**（`regions.ts` 的 `REGION_PALETTE` /
  `assignRegionColors`）。2.38.0 仍是"父色相 ±8°、饱和 0.13~0.21"的连续取色，α 0.30
  把它压进纸色里——同级相邻两块的合成色差实测均值只有 **3.6/255**、最差 0.1/255，
  正是用户说的"每个国家的色块颜色差距很小，像是国内的大区域"。改为 9 格旧地图色板
  （赭红 / 土黄 / 秋香 / 深橄榄 / 苔绿 / 竹青 / 石青 / 藕灰 / 墨褐）后：按同层共享边
  建邻接表，贪心把"与已着色邻居太近"的块换到更远的一格，并在同层尽量不重色。
  实测相邻均值 **26~32/255**、最差 ≥ 14/255；洲一级 12 块用到 9 种颜色。
- **国名上图层**（新增 `components/MapCanvas/regionNameLayer.ts`）：按 `√区块面积`
  定字号（同层均值 ×0.75~1.3 夹取）、宋体、字距 0.22×字号、深褐 `#4a3a28`、α 0.55、
  无白描边。只给 0~2 层建名（郡级不出名，避免与地名抢位）。名字挂在区块层最上层，
  透明度跟 `levelAlphas` 走——与填充/边界同呼吸，缩放时一起淡入淡出。节点**懒创建**
  （该层首次可见时才建），避免"生成区块"那一下建出 200 多个文字纹理。
- **海岸掩膜改用与陆地同一条曲线**（`MapCanvas` 的 `regionMask`）：陆地是
  `land.drawLandPath` 画的 Catmull-Rom 曲线，掩膜此前用的是采样点直线相连的
  **弦多边形**再外扩 3 单位。两者在湾口能差十几个世界单位，于是曲线切掉的湾口仍被
  判成"陆地"——区块填充与边界就画到了海面上（用户截图红框里那片浅色楔形 + 横穿湾口
  的边界线）。改用同一路径后不再外扩（`regionLayer` 在 `coast` 之上，扩出去就是区块
  色压海面），"哪里是陆地"只剩一个事实源。
- **手画取色跟随同一张色板**（`regionEdit.manualRegionColor`）：按黄金比步长在色板里
  跳格取色，撞到父块那一格就顺延一格——同一张图上两套色系会让手画块看起来像"贴上去
  的"。`REGION_WOBBLE.hueSpread` 与 `LocalNode.hue` 随之删除（连续取色的遗产）。

### 未改动

- **几何一律不动**：`buildChildren` 里消耗的随机数**个数与位置**与 2.38.0 逐位一致
  （level > 0 三个、level 0 四个），因此**同一 seed 生成的区块形状与改前完全相同**，
  只有颜色变。旧图执行一次「生成区块」（同 seed）即可换新配色而形状不变。
- 填充 α / 边界线宽 / 边界色 / 静态层次表（2.38.0 的四个源值）、区块贴岸修复、
  共享边去重、`levelAlphas` 的四层共用均不变。

### 验测

- `regions.test.ts` 新增 4 条：「色板 9 格 + 两两合成色差 ≥ 10」「**相邻**区块色差
  均值 ≥ 22、最差 ≥ 12（2.38.0 的均值只有 3.6，这条就是回退探针）」「洲一级 12 块
  用到 ≥ 8 种颜色」「`assignRegionColors` 确定性 + 整层同色也能被拆开」。相邻关系在
  测试里**独立重算**（不 import 生成器的邻接表），避免"用被测实现验证被测实现"。
- 新增 `regionNameLayer.test.ts` 6 条：字号上下限与退化面积兜底、只建指定层级、
  面积门槛、空名/退化多边形跳过、字距跟着字号、重复同步不累积节点。
- `render-stack-guard.test.ts` 新增 3 条：掩膜走 `drawLandPath` 且不再 `mask.poly(`、
  掩膜不向外扩、国名分组挂在填充/边界之上且层级上限 = 2。
- `regionEdit.test.ts` 的 `manualRegionColor` 用例重写为"取色来自色板 + 相邻序号不同色
  + 任何父色都不撞色"。
- `tsc --noEmit -p tsconfig.app.json` 零错误；`src/windows/MapWindow` 全量通过；
  `region-land-audit.test.ts` 的越岸基线（≤3200 点 / ≤16 单位）**逐值不变**，
  反证几何确实未被改动。

### 已知未对齐（承 2.38.0）

- 同屏区块数仍受 `LOD_BLOCK_PX = 360` 限制（国家一级在"视口覆盖大半张图"时可达
  ~40 块 > 参考的 20）。要压到 ≤20 需同时改素材与地名的层级节奏，仍单列 §9 `ALGN-2`。
- 老存档的 `MapRegion.color` 是旧色，重生成才会用色板（渲染期常量已即时生效）。
