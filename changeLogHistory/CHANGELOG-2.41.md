## [2.41.0] - 2026-11-07

> 区块层第四轮：**裁剪重写（色块/线条问题的根治）**、**国家默认数下调**、
> **大陆形状 12 种 + 大陆底色落地**。前两条直接回应「色块跟线还是有问题，先直接
> 仿照逆向目标实现」。

### Changed

- **区块裁剪重写：Sutherland–Hodgman → 可切分的半平面裁剪**（`regions.ts` 新的
  `clipHalfPlanePieces` / `voronoiCellPiecesIn`）。色块与线条问题的**共同根因**终于
  找齐：S-H 逐边连一条链，隐含假设"裁剪结果仍是一条环"；凹容器（陆地环天然有深湾）
  被直线切开时结果是**两块甚至更多**，S-H 只能用一条沿裁剪线的弦把它们硬连成单环 ——
  那条弦就是"横穿整块地、跨过海湾"的细线，而 non-zero 填充又把弦围出来的湾口一起涂上
  区块色。**两种缺陷是同一个根因**。新实现按「环上顺序配对（进→出）+ 线上顺序配对
  （出→进，且必须**成对**出现）」把多连通结果拆成若干条简单环，几何上不可能再拉弦。
  随之删除整套事后补丁：径向钳制（`makeRadialClamp`）、越湾修复（`repairBayCrossings`）、
  接缝修复（`repairPolygonSeams` / `repairClosingSeam`）—— 它们都是在替 S-H 的单环
  假设兜底。
- **区块支持"飞地"**（`MapRegion.pieces`）：凹父块切出的多块单元全部收下，主块承担
  区块身份（种子 / 名字 / 命中），附加块只是同一区块伸出去的部分，各自成环、各自
  填充与描边（`MapCanvas`）。丢掉它们会留下没有区块色的空地，硬连成单环就是飞线 ——
  老文档没有该字段，读作 `undefined`（单块常态）。
- **内部边加"离岸余量"封顶**（`REGION_WOBBLE.coastClearanceRatio = 0.6`）：贴岸段
  现在是陆地环本身（精确裁剪的产物），但内部边的曲折位移是沿法线**双向**的，一条
  距岸只有几单位的内部边会把起伏拱到海面上（实测最远越岸 6.2）。按"边中点到父块
  边界的距离"封顶振幅是**事前**约束 —— 边界自然收直，不需要任何事后投影。
- **国家默认数 20 → 12**（`REGION_LEVELS[0].count`）：参考实现的 `20<J&&(J=20)` 只是
  **上限**，其成图观感是"一块大陆十来个国家"；默认顶满 20 让整图视角密得像拼图。
  用户可在「层级配置」面板自行调回。默认三级合计 232（12 + 60 + 160）。
- **大陆形状 12 种**（`land.ts` 的 `LAND_SHAPES` + `LandOptions.shape`）：正常 /
  多陆地 / 多海洋 / 南北 / 东西 / 星月 / 狭长 / 盘古 / 饼干 / 三大洲 / 类地球 / 零散，
  名称转写自参考面板。实现全部落在 `land.ts` 已有的自由度上 —— 岛数与占纸比（布局）、
  可用半幅压缩（朝向；配**各向异性贴合**把侵蚀游移洗掉的朝向拉回来）、母形谐波与
  特征（形状性格：星月 = k=1 主导的"月" + 星形伴生岛；饼干 = 宽圆负特征沿边"咬口"）。
  **侵蚀管线一个字没动**。形状档只影响一键成图与「只换陆地」档。
- **大陆底色 6 档**（`land.ts` 的 `LAND_BASE_COLORS` + `MapLand.baseColor`）：
  羊皮纸（缺省 = 现状色）/ 暖沙 / 黄褐 / 灰绿 / 青灰 / 粉灰，`bakeCoast` 的陆地填充
  改读 `land.baseColor ?? COAST_FILL.color`，并进 `bakeKey`（换底色即重烘）。
  ⚠️ 参考面板的确切色值未能从逆向源码核出（其底色走贴图/滤镜链），6 档是按参考
  成图观感给的近似，后续拿到确切值只需改表。
- 一键成图弹层新增「大陆形状 / 大陆底色」一行（底色选项带色点）。

### 兼容与代价（显式承认）

- **「正常」档逐字节承诺**：不传 shape 的 `generateLand` 与显式传 `"normal"` 产出
  完全一致（随机数调用序逐位保留）；`generateMap` 不传 shape / landColorId 时陆地、
  布点与 2.40.0 逐实例相同。老文档（无 `baseColor` / 无 `pieces`）照常渲染。
- **2.40.0 的「描边丢弃跳线」保留**（`isRegionJump` 预扫 + 断链）—— 它防的是
  飞地拼环之外残余的自交，成本极低；跳线预扫现在把飞地边也算进中位数。
- **贴岸审计阈值收紧**（`region-land-audit.test.ts`）：精确裁剪 + 离岸余量封顶后，
  12 seed × 20 岛实测越岸点 **110 / 最大 2.9**（旧补丁时代 2748 / 14.1），阈值从
  16 / 3200 收到 **4 / 300**；变异探针同步改为"阈值必须远小于单环拉弦时代的实测值"。
- **国家 20 → 12 的连锁**：全图视角同屏可辨识 = 12 块（≤ 参考上限 20）；LOD 自然
  缩放 `[0.609, 1.362, 2.223]`（⚠️ scale ∝ √count，方向别记反）、交界
  `[0.911, 1.740]`，缩放下限 47% → **37%**；
  「同层不重色」下限从 20 块 ≥8 色改为 12 块 ≥7 色。

### 验测

- `regions.test.ts` / `region-land-audit.test.ts`：阈值收紧 + 守卫改写（见上）；
  旧的「已知残余：自交与越界占极小比例」守卫在新实现下自然通过。
- `land.test.ts` 新增「大陆形状档」组：12 档各验证「合法陆地 + 同种子逐位一致」、
  「正常」缺省兼容、多海洋/三大洲的岛数语义、南北/东西的最大岛长宽比 > 1.25
  （⚠️ 必须量**最大岛**而不是联合包围盒 —— 形状档不锁岛数，多岛联合包围盒量不出朝向）。
- `generator.test.ts` 新增透传两条：盘古恒 1 岛 / 三大洲恒 3 岛；`landColorId` 落
  `land.baseColor`、不传则无该字段。
- 全量：`tsc --noEmit` 零错误、eslint 零告警、MapWindow 全量通过。
