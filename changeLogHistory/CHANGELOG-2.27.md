## [2.27.0] - 2026-11-04

> 地图渲染观感对齐第三批：**素材比例（配比 / 体量）** 与 **背景质感（海面 / 海岸）**。
> 一句话：把「按每格铺满」换成**按预设配比发放配额**，把「一张铺满纸的平铺纹理」
> 换成**有浅滩、有等深线、有暗角、有纸纹的海与陆**。

### Fixed

- **地图窗口起来了但一片空白**（`Uncaught TypeError: Cannot read properties of null
  (reading 'alphaMode')`）：纸纹是本组件 `useMemo` 自造的纹理，卸载时 `destroy(true)`
  会把 `Texture._source` 置成 `null`；而 `MapWindow/main.tsx` 开着 `StrictMode`，
  「挂载 → 跑 cleanup → 再挂载」这一轮里 **`useMemo` 不会重算**，第二轮拿同一张
  已销毁的纹理去烘焙 → Sprite 进 batcher 时读 `_source.alphaMode` 抛 null →
  整个 canvas 渲染中断（报错在 pixi 深处，现象却像"什么都没画"）。
  改为**模块级单例、永不销毁**（`paperGrain.getPaperGrainTexture`，一张 512² 常驻
  ≈1 MB，不随开关窗口增长），并在 `bakeCoast` 补一道「已销毁即当没有」的兜底 +
  两条守卫（单例取用口必须查 `destroyed`、MapCanvas 不得 `destroy` 纸纹）。
- **配比形同虚设**：预设写 `mountain 0.55 / forest 0.30`，实际产出 83% 的山
  （`assignTerrainByGrowth` 把没认领的格全归给主地形，主地形又每格多铺 1 个）。
  现在按 `expandTerrainMix` 的实例数建**配额表**，配额用尽即不再开簇 ——
  预设第一次真正决定画面构成，剩下的格**留成平原**（30% → 实际铺 70%）。
- **陆地外面套着一圈暗环**：`COAST_SHELF` 用的是比海更暗的深绿，画出来像贴纸
  阴影。改为**比海亮**的浅滩（任何地形图的浅滩都比深海亮），并收窄到 20。
- **陆地是"海面纹理乘上去"的**：纸纹参数原本直接传底图（青绿水纹漩涡），
  陆地因此带上青灰旋纹、整体发暗。新增 `paperGrain.ts`：程序生成的**中性灰颗粒**
  （三层值噪声 + 网点，512²，哑光 0.88），陆地才真的是"米黄纸"。
- **城堡和山一样高**：素材 `baseWidth` 是"这张图原来画多大"，不是"图上该多大"，
  135×130 的城郭与 200×127 的山脉按同一尺度摆，聚落立刻压过地貌。
  新增 `TERRAIN_SCALE`（按地形配方归一：山地 1.0 / 丘陵 0.75 / 森林 0.72 /
  聚落 0.52 / 遗迹 0.48），点符号回到"山峰的三分之一"。

### Added

- **等深线**（`coastBake.COAST_ISOBATHS`）：离岸 16 / 40 / 70 世界单位三圈细线，
  与海岸平行、向外递减。海面第一次有了"离岸越来越深"的层次；
  烘焙期算完即烤进纹理，运行期零成本。
- **陆岸内阴影**（`COAST_INNER_SHADE`）：`alignment: 1` 的描边只画在路径内侧，
  模糊 + 陆地遮罩，得到"岸线附近略深、往内陆变亮"的浮起感。
- **海面暗角**（`MapCanvas.SEA_VIGNETTE`）：14 圈窄环从纸缘向内压暗（0.004→0.026），
  海面不再是一块均匀的布；节点 `seaShade` 排在 `sea` 之后（否则被不透明海面盖掉，
  已在 `render-stack-guard.test.ts` 的 `STATIC_STACK` 里钉死）。
- **多片地形**（`CELLS_PER_PATCH = 7` / `MAX_PATCHES = 4`）：区域生长按配额拆成
  若干片互不相连的斑块，页面上才有"几条山脉"这个层级，片与片之间就是平原。

### Changed

- **素材尺寸随格边长补偿**（`BASE_CELL = 92`）：密度档改的是格子大小，素材按同一
  比例缩放，`素材 : 地块` 恒定 —— 繁密档变细不变糊，稀疏档变大不变散。
- **簇内实例微调放宽到 0.9~1.1**（原 0.94~1.06）：同一张贴图摆两次是最刺眼的重复，
  尺寸错开一成以上才不像复制粘贴。
- 海岸白边收细（2.4 → 1.8，0.92 → 0.86）：原来是"一圈雪"，参考实现是细亮线。

### Tests

- 新增 `paperGrain.test.ts` 6 条（灰度/只压暗/同 seed 复现/接缝无断裂/jsdom 降级）。
- `coastBake.test.ts` 按新装配（8 节点）改写三条；模糊参数守卫改钉
  `[9, 5, 1.6, 7]`（浅滩/发光/底色/内阴影）。
- 生成器新增「点符号明显小于山地」一条（钉"什么该大什么该小"，
  原 `scale ∈ [0.75, 1.3]` 的区间断言改成按新语义的上下界）。
- 地图窗口 29 文件 / 525 用例全绿。
