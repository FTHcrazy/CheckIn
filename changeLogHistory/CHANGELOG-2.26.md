## [2.26.0] - 2026-11-04

> 地图渲染观感对齐第二批：**地貌带（P0-1）+ 网格丛簇布点（P0-2）**，
> 证据与取舍见 `docs/review/map-vs-reference-render-analysis.md` §6 / §6.4。
> 一句话：把「按目标总数撒点」换成**网格 + 丛簇 + 地貌带**——同一张图上
> 读得出「南北有差别、同类成片、疏密有呼吸」。

### Added

- **素材第三轴「地貌带」**（`domain/zones.ts`）：`SpriteZone` 四带
  （`snow` 雪带 / `core` 主带＝全带通用池 / `grass` 草带 / `desert` 沙带）+
  `zoneAtY` 纬度分带（北 25% 雪、南 25% 沙，中间按中点切主/草；端点对齐参考实现
  的 `r<H/4`、`r>3H/4`）+ `zonePreference` 取用顺序。两者皆为纯函数。
- 52 张素材逐条标注 `zones`（`SpriteDef.zones` **必填**，漏标编译期即炸）：
  雪峰/雪岭/雪松/雪丘 → `snow`，沙丘/绿洲/风蚀岩/石林 → `desert`，
  圆丘/梯田/阔叶/草丛/疏树 → `grass`，其余山地林木与全部人文素材 → `core`。
- 预设可选 `climate` 锁定全图气候带；「万里雪原」已锁 `snow`（南缘不再冒沙丘）。
- 生成摘要新增「分带」分布（`雪带 18 / 主带 40 / 草带 32 / 沙带 14`）：
  分带一旦失效，摘要里立刻现形，不用靠肉眼比对。

### Changed

- **布点算法重写**（`domain/generator.ts`）：分区中心 + 极坐标撒点 →
  **格网 + 区域生长 + 黄金角丛簇**。
  - 密度改为「目标总数 → 格数 → 格边长」反解（对齐参考实现"改格网尺寸"的做法，
    不再是小图挤成一坨、大图稀得能跑马）；格内实例恒 1~3（主地形 2~4）；
  - 地形用**区域生长**铺，同配方连成一片；孤立格按 25% 保留（连通性先验）；
  - 簇内黄金角螺旋落位 + 同簇共享基准大小，跨格只拦深叠
    （碰撞收缩 `0.55 → 0.35`，**同簇豁免**，同簇只防"同一位置叠画"）；
  - 旋转按体量分级：基准宽 ≥120 走 ±7°，小素材 ±15°（对齐参考实现
    "丘陵 ±15° / 主池 ±5~7°"）。
- 布点按**脚底 y 升序**输出（P1-2）：Pixi 按加入顺序绘制，排序即 z 序，
  前后遮挡符合直觉，零成本。
- `pickTerrainSprites` 新增 `zone` 参数：**本带 → core →（仅当两者皆空）
  同地形任意带**。只要本带有货就绝不跨带——跨带等于没分带。

### Fixed

- **同一地形只有一套画风**：雪原上长阔叶树、沙漠里长针叶林。
- **密度与画布尺寸不联动**：大图铺得稀、小图挤成一坨。
- **到达总数上限时截掉南半边**（铺格顺序改为打乱迭代）。

### Tests

- 生成器 24 条（新增：分带三条、成团一条；改写：重合/超发、旋转分级、
  配方成片），选材 22 条（新增分带四条 + 素材侧两条）。
- 改写三条旧守卫的判据（"钉意图不钉实现"）：核心盒两两相离 → 锚点不重合 +
  同簇层叠合法；点云直径 → 同类最近邻 vs 均匀撒点理论值；rotation ±7° →
  按体量分级。理由逐条记在 review §6.4。
