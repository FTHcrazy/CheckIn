## [2.37.0] - 2026-11-06

> 对照逆向目标（易制地图）成品图的三条交互矫正：区块线贴岸、一陆一大陆、素材体量。

### Changed

- **区块边界线贴岸（越湾修复）**：生成区块时，折线上越出陆地环的点先径向投影回
  岸线（沿海岸平行外海的抖动弧，实测越岸 24.6 单位），跨湾的直弦再沿环岸**绕行**
  补点（`regions.ts` 新增 `repairBayCrossings` / `repairPolygonSeams`，host 折线带
  基线参数表 `HostEdge.us`，父子切片与兄弟共享边界逐位一致）。12 seed × 20 岛实测：
  越岸采样点 6831 → 2748、最大越出 24.6 → 14.1；残余的拼接缝级弦（≤ ~10 单位，
  径向投影在非星形湾的对岸问题）由渲染期掩膜裁掉。守卫 `region-land-audit.test.ts`。
- **区块层挂陆地掩膜 + 共享边去重**（`MapCanvas`）：regionLayer 以 `doc.land` 做
  矢量掩膜（外扩 3 单位盖平滑矢高差），任何来源的跨海边界一律裁掉 —— **旧存档
  不重新生成分区也已可读**；边界描边按端点归一化键去重，相邻区块公共边只描一次，
  alpha 不再叠加成 ~0.54 的"蛛网"（内部边与岸线深浅一致，路径量省近一半）。
- **每块陆地恒 1 个大陆区块**：`buildRegions` 的 level0 数量不再按岛面积分摊全局
  配额（旧口径把主岛切成 2~3 个"大陆"，读起来像"一陆一国"）。默认层级下单陆地图 =
  1 大陆 → 12 洲 → 48 国 → 160 郡，"一个大陆有多个国家"结构成立；层级仍可在
  「层级设置」面板自定义。
- **素材体量总闸 0.42 → 0.32**：最大素材渲染宽 / 最长陆轴实测 p50 12.0% → 9.1%、
  max 15.6% → ≈11.9%，落入逆向目标 ≈8~12% 区间；地形间相对关系（点符号 < 地表 <
  山地）不变。`generator.test.ts` 的陆宽占比上限同步 35% → 15%。
- **旧图迁移提示**：已存地图的区块多边形不自动重贴 —— 对旧图执行一次「重新生成分区」
  即可获得贴岸边界。

### 验测

- 全仓 `pnpm test --maxWorkers=4`：293 文件 / 4047 用例全绿；既有 50 条 regions 测试
  （含「兄弟之间共享的边恰好被使用两次」的严丝合缝守卫）零改动通过。
- 新守卫 `region-land-audit.test.ts`：贴合度（越岸 ≤16 单位 / ≤3200 采样点，阈值
  带防假绿反向断言）、素材比例（≤ 陆轴 15%）、一陆一大陆（level0 = 1 且覆盖 ≥95%）。
