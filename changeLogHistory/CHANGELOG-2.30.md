## [2.30.0] - 2026-11-05

> 地图 **B4-2：折线要素（R-MAP-26）**。终于能画河了：工具栏新增「折线」工具，
> 逐点画出河流 / 道路 / 山脊 / 势力边界，Catmull-Rom 平滑渲染，五档预设样式
> （官道双层、小径碎虚、河流、山脊、边界渐隐），选中后可拖节点、双击线上加点、
> 双击节点删点。渲染栈第一次**中间插层**（8→9）：线压在区块之上、垫在素材之下——
> 路不会盖住山，也不会被区块填充盖淡。

### Added

- **折线几何（纯函数层）**：`polylineGeometry.ts` —— `smoothPolyline`（Catmull-Rom tension 0.5，
  端点镜像外推，与陆地边缘同一条算法，避免"岸是曲线、河是硬折"）、`nearestOnPath` / `distanceToPath`
  （命中与插点共用一条采样路径）、`dashPath`（虚线按弧长切段，缩放时虚段随线宽一起伸缩）。
- **五档样式表**：`polylineStyle.ts` —— `POLYLINE_STYLES` 常量（样式 id 一旦发布不得改名，老文档认它）；
  线宽 = **世界单位** + 屏幕下限 0.75px（`effectiveWidthWorld`）：缩到洲一级一条 2.4 单位的小径只剩
  0.8px，没有下限就是"线画上了但整条消失"。命中容差 = `线宽/2 + 6px 屏幕`（与素材同一档手感）。
- **折线绘制层**：`polylineRender.ts` —— `drawPolyline` 双笔叠画（深褐主线 + 米白内描芯，
  顺序不可反：单根纯色线在米黄纸面上像 CAD 图纸）、虚线、两端渐隐（势力边界）。不挂滤镜。
- **折线绘制工具**：工具栏新增「折线」按钮（与画区互斥的第三种工具态）。单击落点、
  双击 / Enter 收尾（<2 点丢弃并退出，不留幽灵线）、Esc 四级退让、绘制中 Delete 退一个草稿点。
  落库自动选中，右栏浮出属性面板。
- **折线编辑**：拖节点（绝对世界坐标，拖动全程只记一步撤销）、双击线上插点（取**线上最近点**
  而不是鼠标位置，否则新点会把线拽出小尖角）、双击节点删点（删到 <2 点整条线一起删，
  不留点不中的幽灵对象）、Delete 删整条线（可撤销）。
- **折线属性面板**：`components/PolylinePanel/` —— 样式下拉（换档连带 `kind`，回退口径一致）、
  粗细滑杆（0.5~2.5 倍，`coalesceKey` 让一次拖动只占一步撤销）、层级下拉、名称输入
  （本地草稿按 id 重置，不把上一条线的名字带进新线）、删除。
- **折线渲染层**：`WORLD_LAYER_ORDER` 8 → 9，`polylineLayer` 插在 `regionLayer` 与
  `elementLayer` 之间（本项目第一次中间插层——追加到末尾会变成"路盖住山"）；
  折线按层级分容器，随 LOD 权重淡入淡出，与素材同一套规则。

### Changed

- **数据层**：`useMapDocStore` 新增折线六个动作；`DocSnapshot.polylines` 进撤销栈——
  撤销回"从没画过线"的老文档时 `polylines` 键**整个删掉**（零写入），不留 `[]`。
  `updatePolyline` 清空标签、线宽调回 1 倍同样删键。
- **键盘 Delete 分流**：折线绘制中 Delete 退草稿点（线还没落库，不能走文档撤销——
  那会把上一步素材操作撤掉而草稿纹丝不动）；选中折线时 Delete 删整条线（折线优先于素材）。
- **锁定提示补齐**：命中被锁的折线时 `message.info("「折线」层已锁定，先解锁再编辑")`，
  与 B4-1 的素材层同款，不静默。

### Fixed

- **键盘 Delete 曾被 `closeDraft` 无条件抢走**：早期实现里 `!mod && Delete` 一律走
  `closeDraft()`，导致选择模式下素材永远删不掉（`68fba1d` 起即存在）。本轮按
  `tool === "polyline"` 分流后修掉，并补页面级回归用例钉住两个语境。
