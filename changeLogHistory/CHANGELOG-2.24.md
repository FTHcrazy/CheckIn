## [2.24.0] - 2026-11-04

> 移除**记账本**整块功能；新增**证件照换底色页**（checkin 域，base 窗口）。
> 换底色的产品思路参考公开在线工具 `abtool.cn/photosback`（先取透明底、再在前端
> 合成目标底色），但其人像分割在服务端、前端拿不到算法，抠图完全为本仓自研；
> 未复制其源码、文案或品牌。
>
> ⚠️ **数据说明**：`ledger_*` 表的建表逻辑已删除，但**不会主动 DROP 已有表**。
> 老用户库里残留的表与数据仍在盘上，只是无人读写；如需彻底清空请自行 `DROP TABLE`。

### Removed

- **记账本页**（原路由 `/ledger`）整块下线：页面目录、`shared/services/ledger.ts`、
  `handlers/ledger-handlers.ts`、preload 的 `ledger` API、`electronAPI` 类型、
  `db.ts` 的 5 张表与 2 个索引、首页功能卡与「本月支出」统计、侧栏导航项。
- 首页概览 `useHomeOverview` 不再请求支出数据（少一次 IPC）。

### Added

- **证件照换底色页**（路由 `/idphoto`）：支持 1 寸 / 2 寸 / 小 1 寸 / 大 1 寸预设
  与自定义像素尺寸，6 档底色（白/红/蓝/浅蓝/灰/深蓝）+ 取色器，
  纯色 / 上下渐变 / 中心渐变三种渲染，JPG 质量与输出 DPI（同时**改写 JFIF 头**，
  打印店按此换算实际尺寸）。原图 / 成品 / 透明底三视图切换，导出 JPG 或透明底 PNG。
- **自由拖动构图**：按住「成品」视图里的照片直接拖动即可调整位置，锚点用连续值
  （-1 / 0 / 1 = 贴起边 / 居中 / 贴末尾），另配「靠上 / 居中 / 靠下」快捷键与复位。
  拖动按 1:1 跟手换算（屏幕位移 → 成品像素 → 锚点增量），并夹在 -1..1 之间，
  所以「裁切」模式下永远不会拖出空白，也不会把脸切掉。
- 共享 `src/shared/utils/color.ts`：`RgbColor` / `hexToRgb` / `rgbToHex` / `shadeColor` /
  `colorDistance` 等上移，色键页改为转发，两页共用一套判定口径。
- 纯函数单测 37 条：`id-photo-utils.test.ts`（落位 / 锚点夹取 / 拖动换算 / 渐变端点 /
  JFIF DPI 改写 / 命名）、`id-photo-matting.test.ts`（漫水连通性 / 贴边前景 / 羽化 / 去色边）。

### Changed

- `BaseWindow/App.tsx`：路由与 `PAGE_TITLES` 增加 `/idphoto`，移除 `/ledger`；
  首页功能卡「记账本」换成「证件照换底色」。
- `id-photo-types.ts` 的 `IdPhotoOptions.align`（三档枚举）改为 `offsetX` / `offsetY`
  （连续值 -1..1）。三档枚举解决不了「人脸正好卡在相邻两档之间」，只能让作者自己拖。
  `fitRect` 两种适配方式共用一条公式 `(dst - size) * (1 + offset) / 2`，
  `cover` 时 `dst - size` 为负，语义仍是「贴向右/下」，不用分支。

### Fixed

- **首页功能卡被拉高变形**：`.home-page__section` / `__grid` 原本是 `flex: 1 1 auto`
  + `grid-auto-rows: minmax(min-content, 1fr)`，行高会摊掉全部剩余高度——7 张卡在大屏上
  被拉到近 400px 高、内容吊在中间。改为行高按窗口宽度分档定死
  （`116px` / `≤1439` `112px` / `≤1199` `108px` / `≤1024` `108px`），网格不再参与撑高。
- 同一个网格下限 `220px → 240px`：1300px 宽时 5 列只剩 222px，描述被挤成 4-5 行；
  `≤1199px` 收起卡片右侧「进入 ›」（整卡可点 + hover 位移已足够指示），把 40px 行宽让给描述。
- **首页功能卡大屏挤成一整行**：`auto-fit` 在 1920px 下会排出 7 列，7 张卡并成一行细长的
  横条。列宽下限改为 `max(240px, calc((100% - 42px) / 4))`——大屏时「四分之一可用宽度」
  更大，排满 4 列后已无空间放第 5 列，**一行最多 4 张**；窄窗口退回 240px 下限，列数自然减。
  实测 1280 / 1366 / 1440 / 1600 / 1920 / 2560 均为 4 列零溢出；960 最小窗口由 4 列降为
  3 列（卡片 205px → 270px，描述更易读），代价是内容略高于可视区需要滚动。
  描述同时 `-webkit-line-clamp: 3`，超长只截断不外溢。实测 1000–2400px 六档宽度下
  描述零截断、卡片零溢出。
- 构图分组上移到「成品尺寸」之后：原先排在抠图参数之后，首屏看不到，
  而它正是裁切把脸切掉时要用的第一个控件。

### Notes

- **抠图口径是本项目自研**，与色键页有本质差别：色键按颜色全图命中，会把
  人像内部的同色区域一起抠掉（白衬衫遇白底就没了）；本页从画面四边做**边界漫水**，
  只抠与边缘连通、且接近边界主色的区域，被前景围住的同色部分不受影响。
  边界主色取四条边的**中位数**而非平均值——人像肩膀常贴底边，均值会被衣服拉偏。
- 羽化用两遍 chamfer 距离变换（O(n)、无额外队列），距离 1 的像素接近全透明，
  到 `feather+1` 才完全不透明；去色边按 `F = (C - (1-a)·B) / a` 反解纯前景色，
  强度随 alpha 折减，避免小透明度像素把噪声放大成色块。
- **没有做**人脸检测与人脸对齐：Chromium 的 FaceDetector 未默认开启，纯前端
  拿不到可靠的关键点，因此用「裁切 + 自由拖动」代替自动构图，属于能力边界。
- 拖动只在「成品」视图生效：另两个视图画的是原图与未缩放的前景，拖动它们不改变任何东西。
  换照片会把锚点复位到居中，换尺寸则保留——锚点是相对余量的比例，换尺寸后构图仍然成立。
- 控制栏内容较一屏略多，中段可滚动，导出按钮常驻面板底部。
