# Changelog · 2.18.x

## [2.18.0] - 2026-11-03

> 全部改动集中在**地图窗口**（`src/windows/MapWindow/pages/MapEditorPage/`），
> 无新依赖、无数据表、无 IPC 通道。地图文档仍未落库（纯内存态），因此不涉及数据迁移。

### Added

- **嵌套子地图（R-MAP 嵌套子图 · 主方案 Phase 2）**：区块内可内嵌一张独立小地图，递归可嵌套。
  - 数据模型 `MapSubmap`（`types.ts`）+ `MapRegion.submap` / `submapEnterScale` 两个可选字段；
    `bounds` 为**子图本地坐标**（原点居中的自有"纸"），与父图零耦合。
  - 纯函数层：`fitSubmapTransform`（等比贴合 + 居中）、`submapEffectiveScale` / `submapEnterWeight` /
    `enterScaleForRegion`（`lod.ts`）、`submapNodeSpec` / `submapContentPlan` / `submapLevelAlphas` /
    `submapBorderWidth` / `submapBakeResolution`（`MapCanvas/submapRender.ts`）。
  - 场景图：`world` 新增第 5 层 `submapLayer`（z 序在素材与地名之间），每个带 submap 的区块挂一棵
    递归子树；区块多边形做 `clipMask`，子图内容不越界。
  - 两条生成路径落到同一结构：**路径 B 圈定生成**（`carveSubmap`，在区块容器内现场切分，
    边界天然重合）与**路径 A 绑定已有子图**（`embedSubmap` 数据层 + 撤销栈一步提交）。
  - **不会突现的渐入**：父图缩放低于阈值时子图整体不可见（只露父图区块轮廓），越过阈值在
    log2 域平滑淡入；阈值按「区块屏幕长边 ≈ 360px」反推，可由 `submapEnterScale` 覆盖。
  - **子图内部无级 LOD**：用「等效缩放 = 父图缩放 × 贴合缩放」查子图**自己**的
    `naturalScales` / `levelAlphas`，缩进去才逐级显露它自己的洲/国家/郡。
- **子图内容补齐（Phase 2.4）**：子图不再只有分区色块。
  - 子图自己的**海岸**（复用 `bakeCoast`，指纹含分辨率与纸纹，跨 2 的幂次档才重烘，倍率封顶 3）
    与**海面**（仅在子图有陆地时铺，避免在父图陆地中央凭空开出一片海）；
  - 子图分区按层级分容器（容器 alpha 跟层级权重走）、子图素材（脚底锚点 + 层级尺寸因子）、
    子图地名（复用 `labelSync`，屏幕恒定字号）、子图风格滤镜（跟 `submap.style` 走）；
  - 子图节点参与视口粗剔除（整棵一票）。
- **区块选中态与操作面板**：`useMapSelectionStore.selectedRegionId` + `hitTestPolygon`（射线法，
  凹多边形成立）；`RegionPanel` 提供「圈定生成子图 / 聚焦此区域 / 回到全景 / 移除子图」。
  「进入子图」= 推视口（`focusRect`，带 `minScale` 下限，保证进去了就看得见），无独立坐标系切换。
- **陆地海岸形状重做**（`land.ts`）：单层 fbm 换成四层叠加 —— 低频谐波（k=2/3/5/7，1/k 加权）定大轮廓、
  高斯型具名海岸特征（海岬/深湾）造可指认的半岛、**域扭曲**（偏移噪声采样坐标而非半径幅度）
  把岸线拧出海湾、受低频 mask 调制的高频碎齿。另加主轴倾角 ±22°、列宽按面积分配、
  岛数非均匀分布（单陆 55% / 双陆 30% / 三陆 15%）、首块岛面积主导。

### Changed

- **地图工具栏重组**：高频项（撤销/重做/删除/缩放/层级胶囊/生成陆地/生成区块/加标注/导出）留主栏；
  低频项（风格/导出尺寸/字号/层级数/种子/显示分区/清除类）收进「更多」下拉。
  状态指示（分区数 / 陆地种子 / 地名数）保留主栏。
- **`fitSubmapTransform` 的位移改为 `目标中心 − 子图 bounds 中心 × 缩放`**。旧实现直接返回目标中心，
  等于假设"子图内容一定以坐标原点为中心"—— bounds 居中时成立（所以一直没暴露），一旦绑定
  一张内容偏在一侧的地图，整个子图会整体平移出去，且不报错。
- `LAND_AREA_RATIO` 的口径从"必须落在 55%~70%"改为"排布目标"：有机海岸的紧凑度天然低于圆
  （轮廓在自己的包围盒里只占 40%~55%），实测占纸 36%~51%，PRD 验收区间随之放宽到 15%~85%。

### Fixed

- **点击区块没有任何视觉反馈**（用户报障）：`MapCanvas` 新增 `selectedRegionId`，`overlay` 上画三笔
  叠加高亮（淡填充 + 8px 外发光 + 2.2px 细白线，均为屏幕恒定线宽），alpha 跟区块层级权重一起淡出。
- **圈定生成子图后没有后续指引**（用户报障）：生成即自动聚焦该区域；面板补「聚焦此区域 / 回到全景 /
  移除子图」与"后续版本补齐"说明。子图生成后画面只多一层细线，视口停在整张纸时等于没反应。
- **子图分区整体偏移（静默缺陷）**：`carveSubmap` 曾用父图世界坐标生成分区，而渲染层按
  "子图本地坐标 × scale + 区块中心"映射，等于再平移一次 —— 只有包围盒中心恰在原点时才碰巧对得上。
  数据层改用本地坐标系，并有回归用例（含变异验证）。
- **重新圈定后画面仍显示旧分区**：子图结构同步改为按 `submap` 对象引用判断内容是否变化，变了整棵重建。
- **子图内部所有层级同时全亮**：内部层级权重改为每次 `sync` 用等效缩放重算（原实现把权重冻在
  构建那一刻，缩进去也不会逐级显露）。
