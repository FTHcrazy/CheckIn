## [2.31.0] - 2026-11-05

> 地图 **B4-3：折线打磨（R-MAP-26 收口）**。河流会变宽了（源头细、入海粗，笔顺即
> 流向），山脊有了笔刷质感的影线，折线可以闭合（湖岸/轮廓，点回起点即闭合），
> 复制粘贴与方向键微移与素材同一套。B4 三批（图层 → 折线 → 打磨）至此全部闭环。

### Added

- **河流变宽**：`polylineStyle.ts` 样式档新增 `taper: {from, to}`（河流 0.35→1，按
  **弧长**线性插值，笔顺即水流方向）；`polylineGeometry.ts` 新增 `pointTangentAtLength`
  （弧长取点/切向）与 `ribbonPolygon`（变宽带状多边形：左右偏移 + 两端圆头扇）；
  `polylineRender.ts` 新增 `drawTaperedFill` —— 用**一次 `beginFill` 填多边形**而不是
  分段描边：河流带 0.92 透明度，分段描边的圆头接缝会叠画出一串深色斑点。
- **山脊影线笔刷**：样式档新增 `hatch`（颜色/粗细/间距/长短两档），沿弧长在行进方向
  右手侧每 `2.4×线宽` 戳一根垂直短线、长短交替 —— 传统地图 hachure 的极简版；
  落点**确定性**（不掷随机数），重绘之间毛边不跳动。
- **闭合折线**：绘制时点回起点（≥3 点、10px 内）即闭合收尾；属性面板新增「闭合」开关
  （<3 点禁用）；渲染/命中/高亮/双击四处共用 `<3 点按开链` 的退化守卫；store 删点致
  <3 点时自动写回 `closed: false`。
- **折线复制粘贴 / 微移**：剪贴板扩为素材 ∥ 折线联合形态（按 `points` 判别），
  `copy / cut / paste / duplicate / nudge` 五动作内部分流；页面 `Ctrl+C/X/V/D`、
  方向键与 WASD（Shift 加速）对折线生效，与素材同一套快捷键、同一套撤销账目
  （连按合并为一步）。

### Fixed

- **变宽渲染的能力探测**：`StrokeTarget.beginFill` 为可选能力位，目标不支持时
  `drawPolyline` 落回等宽描边 —— 首版实现走进 taper 分支后直接 `return`，
  表现为"河流整条消失"（单测抓到后修复）。
- `dashPath` 一处无效赋值（`break` 前的 `segLen = 0` 永不被读）。

### Changed

- 河流 / 山脊样式档的 `hint` 文案更新（变宽与笔刷已落地，去掉"留待 B4-3"的旧话）。
