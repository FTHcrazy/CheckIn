## [2.22.0] - 2026-11-03

> 地图**素材扩产**（B2，R-MAP-22）：符号从 6 个扩到 **45 个**（6 分类），
> 点要素落位自带地名。来源走 AI 生成（统一手绘水彩风格，锚定原有素材画风），
> **不使用逆向目标 PNG**（红线）；逐张 prompt 记录在
> `assets/sprites/MANIFEST.json`。

### Added

- **素材扩产 6 → 45**：新增山岳 11（尖峰 / 双峰 / 连绵山岭 / 火山 / 石林 /
  雪峰×2 / 雪岭 / 圆丘×2 / 梯田丘陵）、林木 4（森林稀疏 / 繁密 / 松树 /
  阔叶树）、荒漠 6（沙丘×3 / 绿洲 / 风蚀岩 / 碎石荒地）、城郭 7（大城 /
  城镇 / 要塞 / 村落×2 / 茅屋 / 营地）、港渡 5（码头 / 海港 / 灯塔 /
  石桥 / 帆船）、遗迹 6（断壁残垣 / 荒废石门 / 关隘 / 雄关 / 哨塔 /
  山神庙）；素材面板分类扩为 山岳 / 林木 / 荒漠 / 城郭 / 港渡 / 遗迹。
- **点要素地名联动**：城郭 / 港渡 / 遗迹素材落位即从名池挑一个未被占用的
  名字挂成地名（摆一个城市即出现「临江城」，再摆不撞名，双击可改）；
  纯地貌（山 / 林 / 沙丘）不带名。
- **素材来源记录**（`assets/sprites/MANIFEST.json`）：风格模板 + 39 张逐张
  subject + 后处理管线（边界泛洪去白底 / 裁边 / 长边归一 640）+ 3 张重出记录。

### Changed

- 素材登录表 `sprites.ts`：`SpriteCategory` 扩为 6 类，`SpriteDef` 增加
  `names?`（点要素默认名池）；原有 6 张素材的 id / label / baseWidth
  **原样保留**（既有测试与旧地图存档依赖）。
