# CheckIn 小说地图窗 —— 产品规划（PRD v1.0）

> 状态：草案待评审（v1.0 立项版）｜ 作者：产品通 ｜ 日期：2026-09-23
> 一句话定位：**一款服务于小说创作的架空世界地图编辑器，独立窗口承载——随机成图、约束地形、标注即要素、大小图嵌套下钻，并与小说编辑器双窗口联动。**
>
> **与主 PRD 的关系**：本文档由主 PRD（`docs/novel-editor-prd.md`）R28「地图创建」升级拆出。R28 原定位为 WorkerWindow 右栏工具 Tab 内的轻量画布（最小闭环：节点 + 连线 + 导出）；按产品决策升级为独立窗口 MapWindow，并把「随机初始化 / 地形约束 / 手动改地形 / 地点标注 / 大小图嵌套 / 双窗口联动」纳入 v1 范围。**主 PRD 的 R28 状态建议改注：「已升级为独立地图窗口，详见 `docs/novel-map-prd.md`」，原右栏入口仅保留「打开地图窗」快捷方式。**

---

## 1. 背景与问题（为什么拆独立窗口）

网文作者普遍需要维护一张"世界观地图"：大陆格局、势力分布、主角赶路线。当前痛点：

1. **没地方画**：主流编辑器的素材库只有文字卡，地理设定散落在备忘录和脑内，写到第 200 章容易"主角绕远路""两个城方位前后矛盾"。
2. **画了用不上**：即使外部画好图，写作时还要切窗口查图——图与正文、与设定卡互不打通。
3. **粒度断层**：作者真实需要的是"大陆图 → 区域图 → 城镇图"多粒度套娃，单张平面图表达不了"新手村在新手镇哪个角落"。

**为什么独立窗口而不是右栏面板**：地图是"重交互 + 大画布 + 可常驻参照"的形态——编辑时希望地图窗摆在旁边随写随看；右栏 300px 宽度装不下画布，且画布操作（拖拽/缩放/画笔）与码字区抢焦点。独立窗口还带来窗口级隔离红利：即关即销、崩溃互不影响、数据全走持久化层。

**目标用户**：CheckIn 小说编辑器的网文作者（现有 WorkerWindow 用户），尤其是写架空世界 / 有地理设定的长篇作者。

## 2. 目标与非目标

### 目标

| # | 目标 | 衡量方式 |
|---|------|---------|
| G1 | 冷启动建图 ≤ 1 分钟：新建地图 → 选约束 → 随机生成 → 微调 → 落图，全程不查教程 | 埋点 map_open → map_save 首次时长抽测 |
| G2 | 图即设定库：地图上的地点标注与要素库 location 卡一一对应，改一处双处同步 | 联动验收清单（改名/建卡/删除三链路） |
| G3 | 大小图切换丝滑无感：连续缩放跨尺度、小图缩小即成为大图的一角，全程零跳变、零加载等待 | 过渡帧率 ≥ 55fps、跳变次数 = 0 验收演示 |
| G4 | 编辑自由度对齐游戏地图编辑器（二维）：对象任意摆放/旋转/缩放/遮挡，不锁格、零对齐烦恼 | 贴章操作全手势可达、撤销可靠 |
| G5 | 双窗口联动零成本：编辑器绑定地图后，写作侧查图、地图侧查设定卡均 ≤ 1 次点击 | 联动刷新延迟 < 300ms 抽测 |
| G6 | 画布性能达标：地形满铺 + 100 标注下缩放平移不掉帧 | 帧率抽样 ≥ 55fps |

### 非目标（守住"地图工具不做绘图软件"的红线）

| 非目标 | 原因 |
|--------|------|
| 真实地理地图 / 在线瓦片 / 测绘数据 | 继承主 PRD R28 写死的 Non-goal：规避地图数据合规（审图号、境界线表达）与体量问题，只做架空世界 |
| 美术级手绘能力（自由曲线笔刷、贝塞尔编辑、渐变、图层混合、等高线） | 主 PRD §10 已点名风险："地图工具的行业失败教训普遍是做成了绘图软件"。**自由的红线画在"手绘矢量"**：预制符号贴章的自由摆放/旋转/缩放/遮挡属于 v1（RM13，对象级自由，零美术门槛）；自由笔刷塑形、路径编辑仍排除——用户永远不需要"会画画"才能出图 |
| AI 生图（文生图出地图） | 成本与一致性不可控（同一本书两次生成对不上）；随机初始化走本地程序化生成，纯函数可复现 |
| 路径规划 / 自动测距 / 比例尺换算 | 连线距离是作者手工标注的设定值，不是 GIS 计算 |
| 地图窗内编辑正文 | 地图窗与编辑器各司其职，联动靠跳转不靠融合；地图窗内查看设定卡用轻量只读卡 |
| 多用户协作 / 云同步 / 地图模板市场 | 单机产品定位，市场模板放持续池观察 |

## 3. 用户故事

- 作为**网文作者**，我希望新建地图时勾选"三面环海、西面沙漠"这类地形要求，一键随机生成一张像样的世界地图，以便 1 分钟内拿到可用的底图而不是从白纸画起。
- 作为**网文作者**，我希望随机结果不满意就"换一批"，满意后还能用地形画笔手动把某片草原改成森林，以便底图贴合我的设定。
- 作为**网文作者**，我希望在地图上钉一个城池标注并绑定要素库的地点卡，以便改名字时地图和设定卡自动同步、不会出现两套地名。
- 作为**网文作者**，我希望在大地图上放大到"新手村"区域时自动加载新手镇的详细地图，并高亮新手村的位置，以便"大陆 → 城镇"逐层下钻不迷路。
- 作为**网文作者**，我希望在编辑器里把当前章节的场景绑定到某个地点，地图窗随即高亮该地点，以便写到哪、看到哪。
- 作为**网文作者**，我希望在地图上点击某个城池就能看到它的设定卡摘要，以便确认"这座城的势力归属"不用切回编辑器翻要素库。
- 作为**网文作者**，我希望地图按作品归属、编辑器顶栏一键唤起，以便多本书各用各的图，互不串台。
- 作为**网文作者**，我希望每种地形一眼可辨——森林是绿底上长着树、沙漠有沙丘纹、雪山戴白帽、悬崖有陡崖刺线，以便不认字也能看懂自己画的图。
- 作为**网文作者**，我希望把画好的地图导出 PNG 插进作品里，以便发布时当插图用。
- （边界）作为**网文作者**，当地图窗打开但编辑器未开时，我希望点击"在编辑器查看"得到明确提示而不是无响应，以便知道为什么联动没发生。

## 4. 产品结构

```text
MapWindow（独立窗口：默认 1120×720，min 760×480，记忆尺寸/位置，即关即销）
├─ 顶栏：地图切换下拉（当前作品归属分组）+ 新建地图 + 绑定作品徽标 + 导出 PNG + 设置
├─ 左栏（可收起）：标注列表（按类型分组、点击定位画布、含"未绑定要素"提示）
├─ 中央：SVG 画布
│   ├─ 地形层：栅格地形（9 类铺满型底质 + 3 类叠加型符号，图案规格见 §5.1 图例表）
│   ├─ 标注层：地点标注（钉/区域框/自由标签）+ 连线
│   ├─ 联动高亮层：当前场景地点脉冲高亮 / 下钻承接标注高亮
│   └─ 面包屑（嵌套下钻时出现）：大陆 › 东境 › 新手镇
└─ 底部状态条：坐标 / 缩放比 / 标注数 / 自动保存状态
```

**入口（三个，不新增托盘项）**：① 编辑器右栏「工具」Tab 地图卡片（列表 + 绑定 + 打开/新建）；② 编辑器顶栏快捷按钮（已绑定时显示）；③ 地图窗内互相切换。

## 5. 需求清单

### P0 —— 地图窗最小可用（缺一不可）

| # | 需求 | 验收要点 |
|---|------|---------|
| RM1 | 地图 CRUD 与窗口骨架 | 新建/重命名/删除（删除需确认，含子图引用校验）；地图列表按归属作品分组；MapWindow 窗口登记 + 记忆 bounds；四主题复用 ThemeProvider |
| RM2 | 画布基础 | SVG 画布：缩放（滚轮/按钮，10%–400%）、平移（空格拖拽/右键拖拽）、撤销重做（Ctrl+Z/Y，全局单栈覆盖地形与标注操作）；自动保存策略复用编辑器心智（800ms 防抖 + 关窗 flush），全程无"保存中"阻塞感 |
| RM3 | 地点标注 | 四类标注：**地点钉**（图标按要素类型取色）、**区域框**（可绑定子图，见 RM5）、**自由标签**、**连线**（可标距离/险要度文本）。标注可拖拽、编辑、删除；选中标注显示属性面板（名称 / 备注 / 绑定要素 / 绑定子图） |
| RM4 | 标注 ↔ 要素库绑定 | 地点钉可绑定要素库 location 类型要素（下拉选择或"快速建卡"名称带入，复用 `handleSaveEntity` 心智）；**绑定后名称双向同步**（以 SQLite 为唯一事实源，改地图名/改卡名均生效）；未绑定的钉在左栏"未绑定"分组提示，一键建卡补齐 |
| RM5 | 大小地图嵌套绑定 | ① **绑定**：父图任一标注（通常为区域框/城池钉）可绑定子地图（childMapId）；② **进入**：**连续缩放为主路径**——放大经过绑定标注时，越过阈值（默认 2.5×）不弹气泡、不跳切，直接无缝滑入子图（过渡规格见 RM14）；双击绑定标注为快捷进入（面向"我知道我要去哪"的用户）；③ **高亮**：从父图标注 A 进入子图时，子图中设置过"承接父图入口"的标注高亮脉冲 2s 并自动居中——即"加载新手镇地图并高亮新手村位置"；④ **返回**：缩小即无缝退回父图（子图缩成大图一角，RM14）、面包屑逐级跳转 / Esc；⑤ **校验**：保存时环引用检测，拒绝 A→B→A 成环；支持 ≥ 3 级嵌套（大陆 → 区域 → 城镇），多级链式缩放连续穿越不逐级停顿 |
| RM6 | 导出 PNG | 当前视图（或整图）导出 PNG，走主进程 saveDialog + 文件 IPC；可勾选"是否包含标注列表"（图例） |
| RM7 | 作品绑定主地图 | 编辑器侧可为当前作品绑定一张"主地图"（存 userDb config 键 `novel_work_map_binding`，workId → mapId）；绑定后编辑器顶栏显示地图快捷按钮一键唤起 MapWindow；未绑定地图的作品打开地图窗时按无归属处理 |

### P1 —— 地形系统（v1 核心差异化）

| # | 需求 | 说明 |
|---|------|------|
| RM8 | 随机初始化地图 | ① **地形约束模板**（可多选组合）：三面环海 / 四面环海（孤岛）/ 西面沙漠 / 北境雪原 / 中央大湖 / 大河贯境 / 荒芜大陆……每个模板 = 参数化边缘掩码 + 地形偏置；② **生成**：本地程序化生成（value noise + 约束掩码融合），产出栅格地形；③ **可复现**：纯函数 + seed，同 seed 同约束必出同图（对齐 R18 起名工具心智）；④ **换一批**：一键换 seed 重新生成，生成结果对比预览后"采用"才落图；⑤ 生成器纯函数独立文件 + vitest 单测（同 seed 复现性 / 约束边界满足率 / 空池降级） |
| RM9 | 手动地形编辑 | 地形画笔按 §5.1 图例表分两组：**铺满型 9 类**（大海/湖泊/河流/沙漠/草原/森林/山地/雪山/雪原）点选后涂刷栅格，**叠加型 3 类**（悬崖/岛屿/瀑布）作为符号描画在地形之上；笔刷 1/3/5 格三档 + 矩形/圆形区域填充 + 吸管取地形 + 恢复默认草原；画笔操作入撤销栈；涂刷即时渲染（≤ 16ms/帧，局部重绘不整图重绘） |
| RM13 | 自由对象贴章（游戏级编辑自由，二维） | **定位**：对齐游戏地图编辑器的对象级自由——所有标注与装饰符号都是"贴章对象"，**不锁格、亚像素自由摆放**；① **变换**：拖拽移动 / 手柄缩放 / 旋转（Shift 吸附 15°）/ 翻转，操作全程实时预览；② **层级**：对象有前后遮挡序，右键"置顶/上移/下移/置底"，选中对象高亮描边；③ **符号库**：§5.1 图案 + 标注图标（城池/村庄/关卡…）统一为贴章符号库，侧栏拖入画布即放置；④ **多选与编组**：框选多对象、编组/解组（组内相对关系锁定，作为整体变换）；⑤ **对齐辅助**：接近其他对象/网格时磁吸提示（可关），吸附不改变落点自由；⑥ **边界**：贴章仍是预制符号对象——不做自由笔刷塑形与路径编辑（Non-goal 红线），对象总数软上限 500（超出性能降级提示） |

#### 5.1 地形图例规格表（RM8 / RM9 共用，M2 的美术验收基准）

**铺满型**（占满栅格：底色 + 专属纹理图案，图案为 SVG pattern 复用、seed 派生散布，同 seed 同图案）：

| 地形 | 底色 | 独特绘制图案 | 备注 |
|------|------|-------------|------|
| 大海 | 深蓝 | 两行交错的**水平短弧浪纹**，远看是"会动的海"的静态版 | 三面环海等模板的主产出 |
| 湖泊 | 浅蓝 | 细密**点状涟漪**（比海浪短、浅、静） | 中央大湖模板主产出 |
| 河流 | 蓝 | 格内**连续曲线水带**，两岸留 1px 浅色岸线 | 大河贯境模板主产出 |
| 沙漠 | 沙黄 | 同向排列的**新月形沙丘弧**（风纹方向一致） | 西面沙漠模板主产出 |
| 草原 | 草绿 | 稀疏**草叶短线**（散布密度最低，视觉最"空"） | 默认底质（橡皮恢复目标） |
| 森林 | 深绿 | **树木符号**（圆树冠 + 短树干）成簇散布，簇间留林间空地 | 用户示例：一片绿上面有树 |
| 山地 | 灰褐 | **折线山形符号**（▲连绵成脊，山脚阴影线） | |
| 雪山 | 灰蓝 | 山形符号但**峰顶覆白**（雪山帽占符号上 1/3） | 北境雪原模板主产出 |
| 雪原 | 雪白 | 极稀疏**淡蓝冰晶点**，几乎纯白 | 与雪山同模板产出，铺在山地外围 |

**叠加型**（不占格，画在地形层之上的符号层，可跨格绘制、可删除不影响底质）：

| 地形 | 绘制图案 | 交互 |
|------|---------|------|
| 悬崖 | **陡崖线**：沿边界绘制带短刺的粗线（地图学悬崖符号，短刺指向崖底） | 悬崖笔沿格子边界描边，常用于山地/高原与平原交界 |
| 岛屿 | 海中**小型陆块**：椭圆地块 + 一圈沙滩描边 + 中央可选配树/山微符号 | 手动画，或自动识别——海洋格中被陆地包围的孤立地块自动加沙滩描边（两路都支持） |
| 瀑布 | **竖向双线 + 下方水花点**，落在悬崖线或山地边缘 | 点状符号，点击放置 |

**渲染约束（工程验收项）**：① 铺满型图案用 SVG `<pattern>` 定义一次、全图复用，禁止逐格实例化 DOM（4000 格下 DOM 数量红线 ≤ 200）；② 符号散布位置由 seed 派生，同 seed 同约束必出同图案（与 RM8 复现性同一套测试）；③ 缩放时符号随格子等比缩放、视觉密度恒定；④ 图例规格版本化（content.terrain.legendVersion），未来新增地形不破坏旧图回读。

### P2 —— 双窗口联动（P0 的 RM4/RM7 落地后的增量闭环）

| # | 需求 | 说明 |
|---|------|------|
| RM10 | 当前场景地点联动 | 编辑器右栏/章节属性可设置"当前场景地点"（绑定 location 要素，挂当前章节）；设置后广播 → 地图窗高亮该标注（脉冲 + 左栏列表置顶 + 一键居中）；写作侧"写到哪、看到哪" |
| RM11 | 地图侧反查设定卡 | 地图窗点击已绑定标注 → 轻量只读设定卡 popover（名称/别名/摘要/关联关系，内容懒加载）；"在编辑器查看完整卡"按钮：编辑器在开则跳转定位，**未开则 toast 提示并提供"打开编辑器"按钮**（不自动拉起窗口，守零打断） |
| RM12 | 联动实时性保障 | SQLite 为唯一事实源：两窗口任何一方保存 → 主进程向其他窗口广播增量变更（`novel-map-updated` / `novel-entity-updated` 主题，带 mapId/entityId），接收方按需局部刷新；广播防抖 ≤ 300ms；窗口未开则广播自然丢弃（无队列堆积）；地图窗打开时编辑器未开，全量数据从 userDb 直读，不依赖编辑器进程存活 |
| RM14 | 无缝跨尺度缩放过渡（丝滑切换的规格定义） | **效果基准**：小地图持续缩小时**不跳切、不闪白、无加载等待**——子图整体等比缩小并平移，最终精确落位为父图中其绑定标注的边界框（"小图变成大图的一角"），同时父图地形与标注淡入接管画面；放大则反向（父图该区域扩张充满视口，细节替换为子图内容）。**规格**：① **时序**：单尺度过渡 300–450ms，ease-out 曲线；滚轮连续滚动时过渡可叠加续接（不排队不重播）；② **可中断**：过渡途中反向滚动/松开即平滑回退，未过 50% 进度不提交尺度切换；③ **对齐精度**：过渡终态子图边界框与父图绑定标注重合误差 ≤ 1px；④ **渲染**：双层画布同屏（父图层 + 子图变换层），父图在过渡期以**低细节 LOD 快照**渲染（缩略地形 + 标注外轮廓），避免两份全量同时绘制；⑤ **多级**：三级嵌套连续缩放链式穿越，面包屑实时更新；⑥ **降级**：低端机检测帧率 < 40fps 时自动退化为 150ms 快速淡入淡出（仍然无跳变）。**工程红线**：过渡由 transform/opacity 合成器动画承担（对齐全局动画规范），过渡期间禁输入编辑、禁触发自动保存 |

### 明确不做（本期 Won't-have）

河流贝塞尔曲线编辑、PS 式多图层系统（图层混合/蒙版——RM13 的对象前后遮挡序不在此列）、多地图并排联播、比例尺换算、地图分享链接、动图/视频导出——全部进持续池，有使用数据再立项。

## 6. 数据模型与工程落点（对照 AGENTS.md）

**数据层（userDb，SQL 只进 db.ts / handlers）：**

```text
novel_maps(id, work_id, name, seed, content, created_at, updated_at)
  -- work_id 允许为空 = 未归属的共享图册（开放问题 ③）
  -- seed: 随机初始化种子，保留可复现性
  content: JSON 画布文档，schema 定版如下——
  {
    terrain: { cols, rows, cells, features, legendVersion },
        -- cells: Uint8 语义的数字数组，值 = 铺满型地形索引（9 类，见 §5.1 图例表）
        -- features: 叠加型符号数组 [{ id, type: 'cliff'|'island'|'waterfall', cells/points, seed? }]
        --   （悬崖为格边序列、岛屿/瀑布为点位；符号图案规格由 legendVersion 锁定）
    annotations: [{
      id, type: 'pin' | 'area' | 'label' | 'line',
      x, y, w?, h?,                    -- 画布坐标
      name, note, icon?,               -- 展示
      entityId?,                       -- 绑定 location 要素（RM4）
      childMapId?,                     -- 绑定子地图（RM5）
      parentEntryId?                   -- 子图侧"承接父图入口"标注 id（RM5-③）
    }],
    links: [{ fromAnnotationId, toAnnotationId, distance?, note? }],
    viewport: { x, y, scale }
  }
```

- 绑定关系不建新表：作品 ↔ 主地图走 config 键（RM7，低频小数据，对齐 R18 收藏夹先例）；嵌套关系内嵌于 content（随地图文档整体读写）。

**IPC（新建 `electron/handlers/map-handlers.ts`，主进程 `main.ts` 注册）：**

```text
novel-map-list / novel-map-add / novel-map-rename / novel-map-delete（级联清理父图引用）
novel-map-load / novel-map-save（整文档读写；保存时校验 content schema + 环引用）
novel-work-map-bind / novel-work-map-unbind（写 config）
broadcast: novel-map-updated / novel-entity-updated（复用 windowManager 广播，防抖）
```

**窗口登记（新增窗口 5 处，缺一不可）：**
① `src/windows/MapWindow/` 目录（index.html / main.tsx / App.tsx，入口注册 IPC 桥接）；
② `vite.config.ts` `rollupOptions.input` 登记 HTML；
③ `electron/main.ts` `RENDERER_ENTRIES` 登记加载路径 + `createMapWindow()`（默认 1120×720、min 760×480、记忆 bounds、即关即销）；
④ `windowManager` 注册窗口池（接收广播）；
⑤ 打开入口接线（编辑器右栏工具 Tab / 顶栏按钮 → 单实例唤起：已开则 focus 并携带 mapId）。

**渲染进程结构（模块自治，禁止跨窗导入）：**

```text
src/windows/MapWindow/
├── pages/MapPage/
│   ├── MapPage.tsx
│   ├── hooks/          # useMapCanvas / useMapData / useMapLinkage
│   ├── components/     # MapTopBar / TerrainLayer / AnnotationLayer / AnnotationProps /
```

- **跨窗口通信只走主进程**：MapWindow 与 WorkerWindow 互不 import，联动全靠 SQLite + 广播；`shared/ipc/` 封装显式注册函数（带防重复守卫），由 MapWindow 入口调用。

## 9. 风险与开放问题

**风险**

| 风险 | 等级 | 对策 |
|------|------|------|
| 随机地形"不像样"（噪声图审美不可控） | 高 | 约束模板保证大格局、噪声只管细节；换一批 + 手动画笔双兜底；不赌 AI 生图 |
| 嵌套自动进入造成"眩晕/误触" | 中 | RM14 过渡可中断、未过 50% 进度不提交切换；设置保留"关闭自动跨尺度"退回双击进入模式 |
| 无缝过渡的性能悬崖（父图 + 子图双层同屏） | 高 | LOD 快照承担父图过渡期渲染；合成器动画（transform/opacity）+ 帧率探测降级（< 40fps 退化 150ms 交叉淡入）；M3 首日先做性能 spike 验证再铺交互 |
| 双窗广播风暴（保存频繁 × 两窗口刷新） | 中 | 主进程侧防抖 + 增量主题（带 id）；接收方局部刷新；联调压测 300ms 预算 |
| 范围蔓延滑向绘图软件 | 高 | 自由的红线画在"手绘矢量"：贴章对象自由（RM13）属于 v1，自由笔刷塑形/路径编辑/图层混合写死排除；新增美术诉求一律先进持续池、用使用数据投票 |
| 跨窗口状态腐化（两窗同时改同一地图） | 中 | SQLite 唯一事实源 + 整文档乐观锁（updated_at 比对，冲突提示"地图已在另一窗口更新，点击刷新"）——不做字段级合并 |

**开放问题**

1. **地形网格分辨率**（阻塞 M2，工程侧 time-box 2 天）：默认 80×50 够不够"像样"？候选 64×40 / 80×50 / 120×75，拿捏性能与细节后拍板（倾向 80×50 起步、分辨率写进 content 可向前兼容）。
2. **地图归属模型**（阻塞 M1 建表）：work_id 强绑定 vs 允许为空的"共享世界图册"（系列书共用一张大陆图）。**倾向后者**（work_id 可空 + 列表按作品分组显示"共享图册"），建表一次到位成本低。
3. **并发编辑冲突**（M1 需定）：整文档乐观锁（推荐）vs 后写覆盖——单机双窗口场景冲突概率低，但必须给明确反馈而非静默覆盖。
4. **自动进入子地图的阈值**（M3 调参）：2.5× 是否合适，以及是否需要"进入动画"——按演示手感定。
5. **连线距离语义**（M3 非阻塞）：纯文本标注 v1 够用；若后续需要"按比例尺换算马程"，升级为数值字段 + 换算器，schema 已预留 distance 字段。
6. **主 PRD 同步**：R28 状态、§9 步骤五的实施路线需随本 PRD 评审通过后回写主文档（右栏工具 Tab 保留"打开地图窗"入口）。
7. **地形符号美术规格**（非阻塞，M2 前定）：§5.1 图例表锁定的是"图案种类与构成方式"（如森林 = 树冠符号散布），具体形状（圆树冠 vs 三角树、浪纹弧度）由工程出 2–3 套样图截图对比拍板；SVG 符号全部内置于代码（无外部素材依赖，规避贴图版权与 POT 约束）。
8. **跨尺度 LOD 快照策略**（阻塞 M3，工程侧首日 spike）：父图过渡期 LOD 用"静态栅格快照 + 标注外轮廓"还是"降采样实时渲染"；快照何时失效（子图编辑后父图快照刷新时机）——性能 spike 后拍板。
9. **跨尺度缩放的阈值手感**（M3 调参）：自动跨尺度的 2.5× 默认值、"关闭自动跨尺度"设置是否默认藏在设置二级页——按演示手感定；保留双击进入作为永远可用的显式路径。

### 附：一页纸决策摘要

- **是什么**：独立 MapWindow 承载的架空世界地图编辑器——随机成图（约束模板 + seed 可复现）、12 种各具专属绘制图案的地形（9 铺满型 + 3 叠加型，手改）、**游戏级二维编辑自由（贴章对象任意摆放/旋转/缩放/遮挡，RM13）**、地点标注绑定要素卡、**大小图无缝跨尺度切换（小图缩小即成大图一角，零跳变，RM14）**、与编辑器作品绑定 + 当前场景联动。
- **凭什么是独立窗口**：大画布 + 常驻参照 + 重交互，右栏装不下；独立窗口即关即销、崩溃隔离、数据全走持久化。
- **不做什么**：真实地理/瓦片、矢量美术工具、AI 生图、路径规划、地图内写正文、协作云同步。
- **联动三原则**：SQLite 唯一事实源；跨窗通信只走主进程广播；联动永不抢焦点、编辑器未开只提示不拉起。
- **成败判据**：首图 ≤ 3 分钟、建图 7 日留存 ≥ 50%、联动延迟 < 300ms、满地形 100 标注 ≥ 55fps。
