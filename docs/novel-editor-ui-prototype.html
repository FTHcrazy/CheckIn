第三章 断岳

沈砚提着断岳剑，站在寒渊边上。风从谷底卷上来，吹得他衣袂猎猎作响，脚下碎石簌簌落进看不见底的黑暗里。

三年前，青玄真人将他带回青冥宗，那时他还只是个练气三层的少年。如今筑基已成，他却仍记得师父在青冥殿前说的那句话——「剑途无涯，心有归处。」

苏晚从身后走来，手中提着一盏气死风灯。灯光把她半张脸照得发白，她淡淡道：「天煞门的人已经进了谷，你还要等到什么时候？」

沈砚没有回头。他知道她在担心什么——若让慕容绝先一步取走那枚玉简，青冥宗百年基业便要毁于一旦。

他握紧剑柄，指节发白。断岳剑是师父临终前留给他的，剑身有一道三寸长的缺口，据说是当年斩剑冢里那头老蛟时崩的。如今缺口仍在，人却已经不在了。
