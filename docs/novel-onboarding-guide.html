第 1 步 · 新建小说

怎么建

书架页有两个入口，效果一样：

① 顶栏 ＋ 新建作品；② 书架网格最后一张虚线卡片「新建作品」。

弹窗里只有一个书名输入框，没有模板、流派、封面要选——填好名字点 创建并开写（或直接按回车），立刻进入编辑器。

小提示：书名不是承诺，随时能改。第一本书就叫「试写」也完全没问题。

想从现成的书开始？

顶栏的 导入书籍 支持 TXT / DOCX 整本导入，导入后自动切分章节。

第 2 步 · 新建卷与章节

点一下就建好，不用填表

想做什么怎么做
新建一卷左栏底部 新卷（新建在当前作品末尾）
新建一章左栏底部 新章节，或把鼠标悬停在卷头上点出现的 ＋（加在这一卷末尾）
改名双击章名或卷名，回车保存、Esc 取消
调整顺序直接拖拽。拖完可能弹「确认调整」弹窗，核对序号变化后点「确认调整」即可
删除章节悬停章行点 删除 图标 → 再点弹层里的「删除」。会连同历史快照一起删除，不可恢复
为什么叫「第一卷」「未命名」？新建时不用先想名字，序号是按排列顺序自动生成的。改名后显示成「第一卷 · 江湖路远」这样，序号依然保留。
别担心误触：「防误触排序」默认开启（拖动后先弹确认框）。不需要的话在顶栏「排版与偏好 → 设置」里关掉。

第 3 步 · 创建全书总设定

按 Ctrl+Shift+S，或点顶栏的书本图标打开设定中心。

先认识它的结构

设定中心里没有「世界观 / 人物 / 大纲」这样的分区，它的核心概念是「设定分类」：一条分类就是一套全书通用的等级序列，比如：

  • 「修仙 · 经典九层」——练气 → 筑基 → … → 大乘，这就是作品的境界体系
  • 「法宝 · 品阶」——凡器 → 法器 → … → 神器，给物品标品阶用
  • 「功法 · 品阶」——黄阶 → 玄阶 → … → 圣阶，给技能标等第用

左栏管理分类（新建 / 拖拽排序 / 色点），右栏编辑这条序列的等级：每一级有名称、别名、说明，还能配「每阶小层数」（如练气九层）。

新手最快路径：模板库一键套用

设定中心右上角点 模板库，选一条内置预设点 应用到本书——一秒灌入整套体系，灌完仍是普通分类，随便改。内置预设包括：

预设用途
修仙 · 经典九层 / 练气十三层境界体系（练气 9/13 层，筑基起分初期/中期/后期/圆满）
玄幻 · 灵武八境境界体系（八境各分初期/中期/圆满）
都市 · 异能评级F→SSS 倒序评级
洪荒 · 仙道品位 / 法宝 · 品阶 / 功法 · 品阶 / 丹药 · 品阶通用分级，可给行囊物品、技能标注品阶
小抄：常用的按钮都收在每个等级行尾的「⋯」菜单里——编辑名称/别名/说明、新增子层级（把一阶拆成多段）、删除该等级。想一次建一串等级用「批量生成」，支持逐行输入和模板（如 第{n}阶）。

第 4 步 · 写正文与右键菜单

开始写

新建的书还没有章节，正文区会显示「还没有选中章节」——点 写下第一章 就能开写。编辑器是纯文本模式，撑得住三万字的单章。

右键菜单：先选中，再右键

最重要的一条：右键菜单只在选中了文字之后才出现。什么都没选就右键，弹出来的是系统菜单——这不是功能坏了，是设计如此。最快的选中方式：双击一个词。

选中一段文字后右键，菜单从上到下有三组动作：

分组动作效果
记入行囊记入背包把选中的词当作一件物品记进行囊的物品栏，来源章节自动填当前章
新建资料卡角色 地点 势力 物品把选中的词一键建成要素资料卡并加入词库；如果这个名字已存在，会自动变成它的「别名」
绑定到现有资料卡（列出已有要素）把这个称呼挂到已有卡片下，作为别名；已绑定的会显示「已绑定」置灰

正文里的高亮词

写下的角色 / 地点 / 势力名会被自动高亮：单击高亮词打开资料卡，悬停片刻浮出速览卡。不想被打扰的话，点底部状态条的 标注 开/关 即可整体关闭。

放心写：正文自动保存（Ctrl+S 可手动存）。每次保存都会留一版历史快照（每章保留 20 版），顶栏「历史快照」里可预览并一键回滚——回滚本身也会存快照，反悔有路。

第 5 步 · 行囊：主角状态盘点

按 Ctrl+Shift+B 或点顶栏的行囊图标，打开一个独立窗口，专门记主角身上的事：境界、属性、装备、物品、技能、货币、状态效果。

新手只需要知道三件事

概念一句话解释
默认只开 3 个模块总属性汇总、人物属性、境界。点右上角齿轮「模块管理」可随时开启其余 7 个（装备栏、物品栏、技能栏、货币、状态效果、属性映射、备注速记），关掉不丢数据
境界依赖设定中心境界直接复用设定中心里的等级序列。那里没建体系时，境界模块会提示你先去建——从模板库套一条最快的
主角是谁在「境界」模块顶部下拉里选，或回正文右侧「要素」栏的角色卡上点皇冠图标「设为主角」。两边是同一份数据，改一边即可

保存与关窗

改动会先存草稿；空闲 5 分钟或手动点 保存 才写入正式数据。头部会明确显示状态：已保存 · 3 分钟前 / 3 处改动未保存 / 保存中… / 保存失败 · 草稿已保留。

关窗时：还有未保存改动会弹「有改动未保存」，三个选择——保存并继续 / 丢弃改动 / 取消。即使选了丢弃，草稿也已持久化，能在「盘点记录」里找回上一次保存的版本。

常见问题 FAQ

右键没有出现「记入背包 / 新建资料卡」菜单？

这个菜单只在选中了文字后出现。空选区右键弹的是系统菜单。先用鼠标拖选一段文字，或双击选中一个词，再右键即可。

我只是点了下正文里的人名，为什么弹出了一张卡片？

那是「标注层」：已建卡的角色 / 地点 / 势力名会自动高亮，单击高亮词打开资料卡，悬停出速览。如果觉得干扰，点底部状态条的「标注 开/关」整体关闭，关闭不影响任何数据。

新建了作品，正文区为什么是空的？

新书还没有章节。点正文区的「写下第一章」按钮即可；也可以用左栏底部的「新章节」。新书还没有卷时，新建章节会自动建第一卷，不用提前规划结构。

设定中心里找不到「人物」「世界观」分区？

设定中心管理的是全书通用的等级序列（境界、品阶这类阶梯），按「分类」组织。人物、地点等资料在正文右侧「要素」栏维护；世界观可以用自定义分类记录，也可以写进大纲与灵感。新手建议先从「模板库」套一条预设感受一下结构。

改名后卷名变成「第一卷 · xxx」，能只显示自己起的名字吗？

序号（第一卷）由排列顺序自动生成、始终保留，避免章节数多了以后乱序。这是刻意的：拖拽调序时序号会跟着变，方便对齐。

拖动章节为什么弹出确认框？

「防误触排序」默认开启：拖拽会改变章节序号，弹窗里列出了每一处「旧序号 → 新序号」，确认后才生效。不需要的话在「排版与偏好 → 设置」里关掉。

删掉的章节还能找回吗？

不能。删除章节会连同它的全部历史快照一起删除且不可恢复。如果内容重要，先在编辑器里全选复制留存。行囊数据不受影响（独立保存）。

行囊里怎么没有「金币余额」？

行囊的货币模块是「换算器」而不是账本：你自己定义进制（默认 1 金 = 100 银 = 10000 铜），输入大数自动进位试算。金额本身写在正文里，由你掌控。

行囊提示「X 处改动未保存」，关窗会丢吗？

不会静默丢。关窗时弹「有改动未保存」，可选「保存并继续 / 丢弃改动 / 取消」。即使丢弃，草稿也已持久化——打开头部「盘点记录」能找回上一次保存的版本。

行囊的境界模块提示「先建等级体系」？

境界直接复用设定中心的等级序列。按 Ctrl+Shift+S 打开设定中心 → 「模板库」套一条（如「修仙 · 经典九层」）→ 回到行囊就能用了。行囊里的境界改动会同步到角色卡。

保存（Ctrl+S）和设定中心（Ctrl+Shift+S）总按混？

记法：带 Shift 的组合键都是「打开大面板」（设定中心、行囊），裸按 Ctrl+S 才是保存。另外 Esc 可以按优先级关闭浮层，打开错了随手 Esc 就行。
