## 五、纪律（每批开工前必须过一次）

1. **元能力先行**：M5 不得晚于第一个 L3 功能；M8 不得晚于第二个 AI 入口；M3 已有（结构化输出不再重复造）。
2. **不许新增 production 依赖**：token 估算、分块、检索、排序一律自研纯函数；向量库 / embedding / 分词器不进 `dependencies`。
3. **入口可消失**：AI 不可用时，入口必须「隐藏 / 禁用 + 说明 / 有本地兜底」，禁止「点了没反应」与空聊天框。
4. **产出必须沉淀且可溯源**：结构化 AI 产出（名字 / 要素卡 / 摘要 / 关系边）必须有「存入用户库」的出口，并带来源标记（模型 + 时间 + 批次）。
5. **AI 事件落 `ai.db`**，不得写进 `novel_usage_log`（域边界）。
6. **每个功能新增都必须在 `PROMPT_BUILDERS` 登记 + 声明 `OutputFormat`**，不要在业务组件里手拼 system。
